# FinFlow – Personal Finance Dashboard

FinFlow is a modern personal finance dashboard designed to help users manage their income and expenses, track transactions, and understand their financial activity through a clean and intuitive interface.

Built with Next.js, React, TypeScript, and Tailwind CSS, FinFlow focuses on providing a simple and organized financial management experience.

## ✨ Features

- **Dashboard Overview** – View total balance, income, and expenses at a glance.
- **Transaction Management** – Add, edit, and delete income and expense transactions.
- **Transaction Search** – Quickly find transactions.
- **Filtering and Sorting** – Organize transactions based on their type and date.
- **Financial Analytics** – Visualize financial activity through charts.
- **Settings Management** – Update profile information and currency preferences.
- **Local Storage Persistence** – Keep transaction and settings data saved in the browser after refreshing the page.
- **Responsive Interface** – Designed to provide a consistent experience across different screen sizes.

## 🛠️ Technologies Used

- **Next.js** – React framework for building the application.
- **React** – Component-based user interface.
- **TypeScript** – Static typing and improved code reliability.
- **Tailwind CSS** – Utility-first styling.
- **Zustand** – State management.
- **Recharts** – Data visualization and financial charts.
- **Local Storage** – Client-side data persistence.

## 🚀 Getting Started

Follow these instructions to run FinFlow locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/tsi-123/finflow.git
   ```

2. Navigate to the frontend directory:

   ```bash
   cd finflow/frontend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open your browser and visit:

   ```text
   http://localhost:3000
   ```
